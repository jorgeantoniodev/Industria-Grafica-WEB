# Calidad de código web

Antes de crear o modificar los archivos cubiertos, leer completo `~/.gemini/standards/web-code-quality.md` y aplicar sus secciones pertinentes. Resolver `~` como el perfil del usuario, no como una carpeta del repositorio.

Este es un archivo de referencia propio, no una Skill ni una ruta descubierta automáticamente. Esta regla y `GEMINI.md` ordenan su lectura. No copiar su contenido aquí: la fuente personal sigue siendo única.

Si el archivo falta o no se puede leer, comunicar la ruta y detener la modificación; no inventar su contenido. Las configuraciones existentes de versiones, formato y herramientas del proyecto mandan sobre los valores por defecto del estándar, sin permitir omitir seguridad o validaciones.

Aplicar también a cambios pequeños. No activa predeploy ni preparación para exportar componentes, no obliga a instalar librerías y no autoriza reformatear o refactorizar partes no solicitadas.
